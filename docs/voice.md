# Voice principles

Copper Owl's recommendations follow a small set of voice rules. These are the rules to apply when writing any new rule module or copy.

## The big picture

The voice is **a calm field guide left on a table** — third-person observational, mentor-tone, mature, never sweaty-gamer-bro. Imagine an Audubon Society guide written for GW2 instead of birds.

## Concrete principles

### 1. Third-person observational, never first-person

❌ "I'd recommend continuing your Personal Story."
❌ "You should finish Chapter 5 first."
✅ "Continuing the Personal Story unlocks the racial finale."
✅ "Chapter 5 anchors the world for everything that comes after."

The mentor is reading a map and pointing at it, not telling the player what to do.

### 2. "This session" not "tonight"

Players run Copper Owl at all hours and in all timezones. "Tonight" assumes a Western evening session. "This session" is universal.

### 3. Concrete details over vague gestures

❌ "A few chapters left."
❌ "Some rewards available."
✅ "4 chapters remain — about 2 hours total."
✅ "Rewards: 10 AA per daily, capped at 1300/week."

If the engine has account data, use it. If it doesn't, give the player the actual numbers from canonical sources (wiki, official patch notes).

### 4. Honest about skipping

Every recommendation should make it clear that skipping is fine. The default should never feel like an obligation.

✅ "Skippable, but anchors the world for everything that comes after."
✅ "Worth knowing if you'd rather not."
✅ "Optional — but if any of this resonates, here's the entry point."

### 5. No FOMO

Never imply the player has missed something irrecoverable. Living World episodes are buyable. Festivals come back yearly. Patch context can be read at any time.

❌ "You missed the Halloween event — that's gone now."
✅ "Halloween runs every October. Easy to catch next time."

### 6. Reset-awareness shapes urgency, not the recommendation itself

When daily reset is imminent (within 30 min), urgency wording is appropriate. Outside that window, recommendations should not invoke "before reset" framing.

✅ (Within 30 min of reset): "Reset in 12 min — finish today's dailies."
✅ (Normal window): "Continue weekly Wizard's Vault objectives."
❌ (Normal window): "Hurry to finish before tonight's reset."

### 7. Field-guide flavor lines are optional but treasured

When a recommendation has a "flavor" line, it's a single italicized observation in the voice of an older traveler or mentor. Never first-person, never breaking the field-guide frame.

✅ "*The mentor sets the map down on the table. 'Here is where everyone starts.'*"
✅ "*The owl tilts its head. 'The forest grew while you were away. Not so much that you would lose your way.'*"

Use sparingly — one or two recommendations per surface, not every card.

### 8. Source citations are first-class

When a recommendation references mechanics, items, or schedules, link to the canonical source. The GW2 Wiki is the primary source for everything. Use `/wiki et` for the canonical Event timer page.

✅ Sources field on a recommendation: `[{label: 'Event timers', url: 'https://wiki.guildwars2.com/wiki/Event_timers'}]`

### 9. Recommend with conviction, permit deviation explicitly

The "honest about skipping" principle (#4) governs how individual recommendations frame the option to skip. This principle governs the *default* recommendation itself.

Copper Owl's value depends on having a clear opinion. A wishy-washy recommendation ("you could do X or Y or Z, depending on preference") tests worse than a directive recommendation paired with explicit permission to deviate ("Heart of Thorns is the natural next step. Path of Fire works too if mounts sound more appealing — both expansions stand alone.").

The two halves are equally important:

- **Conviction**: name the recommended default clearly. Don't list alternatives as equals.
- **Permission**: explicitly name what else works. Don't imply the default is mandatory.

✅ "Heart of Thorns is the natural next step. Path of Fire works too if mounts sound more appealing — both expansions stand alone."

✅ "Continue the Personal Story. The racial finale chapter is two sessions away. Skippable, but worth knowing if Living World Season 1 comes up later."

❌ "Some players prefer HoT first; others go straight to PoF. Both are valid."

❌ "You should finish HoT before moving on."

The pattern: lead with the recommendation, follow with the alternative named explicitly, close with the reason both work.

This principle is informed by player psychology research showing that perceived sense of progression correlates strongly with engagement, and that decision fatigue from too-many-options-presented-as-equal reduces satisfaction. Players want to be told what to do, with the freedom to deviate. Copper Owl provides exactly that.

## Common drift patterns to catch

- **Voice slipping to first-person.** "I'd suggest..." → rewrite as observation.
- **Over-flavorful prose.** If a recommendation reads like fantasy fiction, trim it. The field guide is matter-of-fact, not florid.
- **Hedge-words instead of specifics.** "Some" / "a few" / "various" → replace with numbers.
- **Time-of-day assumptions.** Anything with "tonight," "this evening," "before bed" → "this session."
- **"You should."** Almost always replaceable with the observation that motivates the should.

## When in doubt

Read the prose out loud as if a 50-year-old librarian were saying it. If it sounds wrong in that voice, it probably is.
